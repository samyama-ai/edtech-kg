# Benchmarks

**Empty today.** One `.cypher` per query with its expected top-N result, mirroring the
Samyama benchmark book format.

This is where the traversals for `docs/questions.md` land, so that each ✅ question has a
query that can actually be run rather than a mark somebody assigned — tracked as
**edtech-kg#22**. A question nobody can express as a traversal is a question the schema
does not serve, and the mark is wrong; writing the queries is the cheapest test of the
ontology there is.

Said plainly rather than left as an empty directory with a template note, because an empty
directory reads as "nothing to do here" and the opposite is true.
